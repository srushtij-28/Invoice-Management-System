# Invoice Management System

A simple modular Python application for managing customers, products,
and invoices.

## Features

- Add customers
- View customers
- Search customers
- Delete customers
- Add products
- View products
- Search products
- Delete products
- Create invoices
- Automatic subtotal calculation
- Automatic GST calculation
- Automatic grand total calculation
- Search invoices
- Delete invoices
- JSON data storage
- Modular project structure

## Technologies

- Python
- JSON
- File Handling
- Datetime
- Functions
- Python Modules
